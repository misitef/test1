# 立冬 · 添望（V7.3 · 90 秒 · 十幕）

送给小丰的立冬网页。9:16 竖屏动画，90 秒，十幕，全部踩《给某某》的拍点（55 BPM，首拍 0.94s，一小节 4.3636s）。

## 怎么看
1. 把整个文件夹放在任意位置（不要拆散素材）；
2. 双击 `index.html`；
3. 点「点 击 开 启」。

Chrome / Edge / Safari 均可，手机竖屏最佳。建议戴耳机。

- 写实剧封（回忆照片卡）：A2 梧桐大道右下方、A3 教室桌面、A5 路灯上方 —— 只在"回忆"里出现，是记忆的物证。

## 音频
优先级：`gei_某某.mp3` > `gei_某某.mp4` > 内置 90 秒合成配乐。
当前素材包内是 `gei_某某.mp4`（H.264 容器，299 秒，44.1kHz 立体声）。音量 0.35，第 6 幕压低 40%，第 10 幕淡出。
没有配音，祝福用打字气泡 + 轻叮音效代替。

## 调试参数
- `?t=45000&freeze=1` 冻结在第 45 秒
- `?autoplay=1&t=30000` 从第 30 秒真播
- `?pause=52000` 播到 52 秒自动暂停
- R 键重播；`window.__dongzhi` / `window.__tl` 可读状态

## 播放
- 点击封面开始，全长 **90 秒**（1.0 倍速，与 BGM 同步）。
- 播完停在最后一帧，底部浮出「点 击 任 意 处 重 播」；**点屏幕任意位置或按任意键**即回到封面重新看（手机、电脑都一样，不需要键盘）。
- 封面提示只有「全 长 90 秒」，不再有佩戴耳机之类的建议。

## 屏幕适配
页面按 9:16 竖屏构图。宽屏 / 平板打开时，舞台两侧（或上下）的留白不会留黑：用当前画面的模糊镜像铺满，颜色跟着每一幕走（雪夜蓝 → 梧桐金 → 汤圆红 → 孔明灯靛）。手机竖屏则整屏铺满。
